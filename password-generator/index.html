❓ Frequently Asked Questions

How long should my password be?

For most accounts, 12-16 characters with a mix of all character types is sufficient. For sensitive accounts (email, banking), aim for 20+ characters. Every additional character exponentially increases the time required to crack it.

Are these passwords truly random?

Yes. The passwords are generated using your browser's built-in crypto.getRandomValues() API, which provides cryptographically secure random numbers. They are not based on predictable algorithms like Math.random().

Are the passwords stored or saved anywhere?

No. All generation happens entirely in your browser. Passwords are never sent to any server, saved to any database, or logged. Once you leave the page, the generated password is gone unless you've saved it elsewhere.

Should I use a password manager?

Absolutely. A password manager (like Bitwarden, 1Password, or Apple Keychain) securely stores your unique passwords for each site so you don't need to remember them. This lets you use long, random passwords everywhere without reusing passwords.

What makes a password strong?

Three factors: length (longer is better), complexity (mix of uppercase, lowercase, numbers, and symbols), and uniqueness (never reuse passwords across different sites). A 16-character password with all four character types has 10^30+ possible combinations.

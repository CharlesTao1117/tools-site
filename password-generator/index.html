FAQ

Are these passwords truly random?

Yes. Generated using crypto.getRandomValues() — the same cryptographically secure randomness your browser uses for TLS. Not Math.random().

Are passwords saved anywhere?

No. Everything happens in your browser. Passwords are never sent to any server or stored in any database. Once you leave the page, the password is gone.

How long should my password be?

12–16 characters with all character types is sufficient for most accounts. For sensitive accounts (email, banking), aim for 20+ characters. The entropy estimate shown above helps quantify your password's strength.

What does the entropy number mean?

Entropy measures uncertainty in bits. Each bit doubles the number of possible passwords. 30+ bits is medium, 50+ is strong, and 70+ is very strong — practically uncrackable with current technology.

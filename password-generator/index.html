How to Use the Password Generator

Step 1: Set your desired password length using the slider (4–128 characters) or click a preset. Longer passwords are more secure.

Step 2: Check which character types to include: Uppercase (A-Z), Lowercase (a-z), Numbers (0-9), and Symbols (!@#$%^&*). Using all four types maximizes entropy.

Step 3: Optionally enable "Avoid ambiguous characters" to exclude easily confused characters like O/0 and I/1/l for better readability.

Step 4: Click Generate — the password appears instantly with a strength indicator showing Weak, Medium, Strong, or Very Strong.

Step 5: Use the Copy button to copy the password to your clipboard. Store passwords in a password manager like Bitwarden or 1Password — never in plain text files or notes.

FAQ

How does the password generator work?

Select your criteria (length and character types) then click Generate. Each click produces a new random password using crypto.getRandomValues — a cryptographically secure randomization API built into modern browsers. No passwords are stored or transmitted.

What makes a password strong?

A strong password has 12+ characters with a mix of uppercase, lowercase, numbers, and symbols. Longer passwords are exponentially harder to crack — a 16-character password with all character types has over 95 bits of entropy, making brute-force attacks impractical even with massive computing power.

Should I include all character types?

For maximum security, yes. Including each character group significantly increases the character pool size and therefore the entropy. A 12-character password from all four sets has far more combinations than one from only lowercase letters.

What is password entropy?

Entropy measures password randomness in bits. Each additional bit doubles the number of possible passwords. Entropy = log₂(charset_size) × length. For example, a 16-character password from a 72-character pool has 16 × log₂(72) ≈ 98.7 bits of entropy — considered very strong.

Why avoid ambiguous characters?

Characters like O/0 (letter O vs zero), I/1/l (letter I, digit 1, lowercase L) are easily confused in some fonts. Avoiding them makes passwords easier to read and type manually — useful when you can't copy-paste. This slightly reduces the character pool but may improve usability.

Are passwords generated here safe?

Yes. All password generation happens entirely in your browser using the Web Crypto API. No passwords are ever sent to any server. The page can work fully offline. The generator uses true cryptographic randomness, not predictable pseudo-random algorithms.

FAQ

Does it count weekends?

This counts all calendar days. For business days only, you'd need to manually exclude weekends from the result.

Does it handle leap years?

Yes. The JavaScript Date object handles February 29 and varying month lengths correctly for all dates from year 1 to 9999.

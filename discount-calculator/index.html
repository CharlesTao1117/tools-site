❓ Frequently Asked Questions

How do I calculate a 20% discount?

Multiply the original price by 0.20 to get the discount amount, then subtract from the original. For example, $100 × 0.20 = $20 off → final price is $80.

What's the difference between % off and $ off?

Percent off (%) scales with the price — a higher-priced item saves more. Fixed amount off ($) is the same dollar discount regardless of price. Use % off for percentage-based sales, $ off for coupons with a fixed value.

Can I stack multiple discounts?

This calculator handles a single discount. For stacked discounts, calculate sequentially: apply the first discount, then apply the second discount to the resulting price. Note that the order matters.

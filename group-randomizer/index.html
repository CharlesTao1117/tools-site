📖 How to Use

Step 1: Paste your list of names into the text box. Names can be separated by line breaks or commas — the tool auto-detects the format.

Step 2: Choose the number of groups (2–10) using the slider or number input.

Step 3: Click Randomize Groups. Each name is assigned to a group using a fair Fisher-Yates shuffle.

Step 4: Review the results, use Redistribute to re-shuffle, or Copy Results to paste them anywhere.

❓ Frequently Asked Questions

How does the Group Randomizer work?

Paste a list of names (one per line or comma-separated), choose how many groups you want, and click Randomize. The tool uses a Fisher-Yates shuffle algorithm to assign each name to a random group for a truly fair distribution.

What's the maximum number of names I can randomize?

There's no hard limit — the tool works with any number of names. For best performance, we recommend up to 1,000 names. All processing happens locally in your browser; no data is sent to any server.

Can I save my group assignments?

Yes! Use the Copy Results button to copy all groups to your clipboard and paste them anywhere — a text document, email, chat, or spreadsheet. Your input text is also saved automatically in your browser so you won't lose your list if you close the page.

Is the randomization truly random?

The tool uses the Fisher-Yates (Knuth) shuffle algorithm, which produces a uniformly random permutation. Each name has an equal probability of ending up in any group. Click Redistribute to re-shuffle at any time for a new random assignment.

What can I use this for?

Common uses include: assigning students to project teams, creating sports teams from a roster, randomizing breakout room groups for workshops, picking Secret Santa groups, splitting party guests into teams for games, and any situation where you need fair random group assignments.

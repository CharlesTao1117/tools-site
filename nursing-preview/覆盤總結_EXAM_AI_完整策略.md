## 1. 產品定位與核心 Thesis

**一句話產品定義：**
> 不是賣「課程」，而是先賣「診斷與方向感」。使用者先因為免費工具進來，再因為弱點分析感到有價值，最後才決定付費。

**目標用戶：** 台灣護理師國考考生（每年約 1.5-2 萬人報考）
**定價：** NT$599/月（單一方案）
**年繳：** NT$3,990（≈ NT$333/月，省 44%）
**平台：** LINE Bot（主要）+ Web 工具站（引流輔助）

**競爭定位（vs 阿摩）：**
| 維度 | 阿摩 (Yamol) | 本產品 |
|:-----|:-------------|:--------|
| 題庫 | UGC 上傳，品質不一 | AI 結構化解析 |
| 解析 | 網友留言 | 分層：正常 + 小學生 + 臨床 |
| 診斷 | 無 | 六維思考模式雷達圖 |
| 記憶 | 無 | SM-2 間隔記憶系統 |
| 學習策略 | 無 | MIT 學習法 (3 Prompts) |

### 分層架構

```
                   ┌──────────────────────────┐
                   │  🆓 免費層（零 AI 成本）   │
                   │  7 種純前端可實作策略      │
                   └──────────────────────────┘
                               │
                   ┌──────────────────────────┐
                   │  💰 付費層（需 AI/DB）    │
                   │  8 種差異化護城河策略      │
                   └──────────────────────────┘
```

### 🆓 免費層（零 AI 成本 — 靜態 JSON + JS）

| # | 策略 | 核心概念 | 實作方式 | 科學基礎 |
|:-:|:-----|:---------|:---------|:---------|
| 1 | **Active Recall** 主動回憶 | 不看選項先回想答案再作答 | 先顯示題目，答案區塊折疊 | Roediger & Karpicke (2006) |
| 2 | **Feynman Technique** 費曼學習法 | 分層解析：正常版 → 小學生版 | 每題 JSON 含 3 層 explanation | 自創差異化策略 |
| 3 | **Elaborative Interrogation** 深度追問 | 不只給答案，追問「為什麼 A 對、B 錯」 | 每個選項獨立解析 why_wrong | Willingham (2007) |
| 4 | **Interleaved Practice** 交錯練習 | 混合科目隨機出題 | Math.random() 跨科目 shuffle | Rohrer (2012) |
| 5 | **Error Pattern Categorization** 錯題分類 | 每題標記：知識性/邏輯性/陷阱性 | 前端 tagging 系統 | 自創分類法 |
| 6 | **Distractor Analysis** 干擾選項分析 | 每個錯誤選項拆解誘答原理 | why_wrong_A/B/C/D JSON 欄位 | 測驗理論 (IRT) |
| 7 | **Concrete Examples** 具體案例化 | 每題附一句臨床情境 | clinical_scenario JSON 欄位 | 自創 |

### 💰 付費層（需 AI + 資料庫追蹤）

| # | 策略 | 核心概念 | 技術需求 | 科學基礎 |
|:-:|:-----|:---------|:---------|:---------|
| 8 | **SM-2 Spaced Repetition** | 錯題自動排 1/3/7/14/30 天覆習 | PostgreSQL + Cron | Wozniak (1987) |
| 9 | **六維思考雷達圖診斷** | AI 分析錯題歸因 → 視覺化弱點 | Gemini Flash + Chart.js | 自創 MIT 方法 |
| 10 | **MIT Prompt 1** 核心思考模式 | 上傳 PDF → AI 提煉專家思維 | GPT-5.5 + RAG | 自創專利方法 |
| 11 | **MIT Prompt 2** 爭議點分析 | 學術爭議 + 陷阱題提醒 | GPT-5.5 | 自創 |
| 12 | **MIT Prompt 3** 深度理解題 | 區分真理解 vs 死背的變形題 | GPT-5.5 | 自創 |
| 13 | **Time Pressure Training** | 45 秒倒數模擬 CBT | 前端計時 + DB 紀錄 | 測驗理論 |
| 14 | **AI Mnemonics Generator** | 難記知識點 → AI 自動編口訣 | Gemini Flash | 記憶術 |
| 15 | **Smart Wrong Question Book** | 自動歸類錯題 + 推薦類似題 | DB + 協同過濾 | 自創 |

## 6. 技術成本架構（100 付費用戶估算）

```
LLM 路由策略：
  80% 簡單任務 → Gemini Flash    ≈ NT$0.02/次
  15% 中等任務 → Gemini Flash+CoT ≈ NT$0.08/次
   5% 深度任務 → GPT-5.5          ≈ NT$0.50/次

每月固定成本：
  Hetzner VPS        NT$140
  Gemini Flash API   NT$500
  GPT-5.5 API        NT$500
  LINE 方案 (Push)   NT$1,600
  網域               NT$25
  ─────────────────────────
  合計              NT$2,765/月

收入：
  100 付費用戶 × NT$599 = NT$59,900/月
  毛利率：~95.4%
```

### 關鍵成本控制規則

1. **免費層絕不呼叫 API** — 所有解析預先計算存入 JSON
2. **付費層 80% 用 Gemini Flash** — 只有深度診斷才用 GPT-5.5
3. **LINE 多用 Reply（免費）**，Push 只用在群組推播
4. **靜態託管 Cloudflare Pages** — $0 託管成本

FAQ

What can QR codes store?

URLs, text, phone numbers, emails, SMS, WiFi credentials, and more. URLs are most common — scanning opens the link on a phone.

Do I need an app to scan?

No. Modern phones (iOS 11+, Android 9+) scan QR codes with the built-in camera app. No extra software needed.

Do QR codes expire?

No — the code itself is a static image. It will work forever as long as the encoded content (e.g., the website it links to) still exists.

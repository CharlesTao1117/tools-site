❓ 常見問題（FAQ）

QR Code 可以包含哪些類型的內容？

網址（URL）、純文字、電話號碼、電子郵件、簡訊、WiFi 設定、vCard 名片等。最常見的是將網址轉換為 QR Code，手機掃描後直接開啟網站。

掃描 QR Code 需要安裝 App 嗎？

現代手機（iOS 11+ 及 Android 9+）的內建相機 App 即可直接掃描 QR Code，不需要額外安裝軟體。

QR Code 有期限嗎？會失效嗎？

QR Code 本身沒有有效期限。它只是一個圖形編碼，儲存的是內容本身（如網址）。只要內容指向的網站或資訊還存在，QR Code 就永遠有效。

QR Code 可以下載什麼格式？

目前支援下載為 PNG 格式，背景透明，適合用於印刷、網頁、數位看板等各種場景。

產生的 QR Code 解析度夠印刷嗎？

選擇「大 (400px)」尺寸即可滿足一般印刷需求。若需要更高解析度，建議用向量格式（SVG），此功能將在後續版本提供。
